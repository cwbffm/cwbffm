## Sobre mim

Atuo com infraestrutura de TI em ambientes híbridos e multicloud, com foco em Oracle Cloud Infrastructure (OCI), administração de sistemas e automação de rotinas operacionais.

Aqui compartilho scripts, adaptações, colaborações e documentação para Linux, Windows, cloud, redes, monitoramento e backups. O objetivo é tornar tarefas recorrentes mais simples, padronizadas e fáceis de manter.
